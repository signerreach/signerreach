# Release and submission status

SignerReach is an **unreleased implementation** as of this book's initial preparation. The Rust workspace currently uses version `0.0.0`. No versioned distribution or security audit is claimed here.

The proposed first release may use version `0.1.0` after an explicit maintainer decision, clean release builds, complete notes, and updated public documentation. **No tag should be treated as published before it exists in the repository.**

## Scope of a first release

The coherent initial candidate contains the implemented Rust `check` and `fetch` commands, deterministic text/JSON reports, documented limitations, fixtures, evidence and a development-only replay harness. Protocol 30 compatibility and future contributor enhancements are separate work.

The [submission pack](https://github.com/signerreach/signerreach/blob/main/submission/submission-pack.md) and [readiness audit](https://github.com/signerreach/signerreach/blob/main/docs/readiness-audit.md) provide a traceable, program-neutral overview. Eligibility, deadlines and application status must be verified against the actual program before submitting.
